# MachineLib

Machine APIs for [Galacticraft](https://github.com/TeamGalacticraft/Galacticraft)
on Minecraft 1.21.1, with Fabric and NeoForge artifacts built from a shared
Architectury common module.

See [the multiloader migration guide](docs/MULTILOADER_MIGRATION.md) for artifact
coordinates and API changes from the Fabric-only release.
